# Clases de vuelo · UCA&Air

Página para apuntarse a las clases de vuelo con doble mando de la asociación.
Muestra las próximas clases, deja reservar plaza y tiene una vista para la organización (`?admin`).

- `index.html`: la página.
- `config.js`: pon aquí la URL `/exec` de la aplicación web de Apps Script. Si está vacía, la página funciona en modo de prueba y no guarda nada.

El código del servidor (Apps Script) y la guía de instalación se guardan fuera de este repositorio, porque contienen el identificador de la hoja de datos.
